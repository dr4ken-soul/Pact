# Pact Marketing

## Copy-ready introduction

Meet Pact, a Bitcoin Cash payment prototype for AI agents.

Set an approved recipient, a per-payment cap, and an expiry. An agent can propose a payment, but the wallet owner reviews and signs each transaction through WizardConnect. The agent never receives the wallet keys.

Pact is built to make agent-initiated BCH payments easier to control and verify. Its spending rules are app-level checks, and every transaction still requires the owner's approval.

## Mainnet demo proof

Pact's WizardConnect payment flow has also completed a real 1,000 sat BCH Mainnet payment. It confirmed in block 978164 with a 226 sat network fee. [View the confirmed transaction](https://blockchair.com/bitcoin-cash/transaction/3016046b74c212788c08d99b7637458edfaa2fcc1ab3b71682aa542182c19704).
